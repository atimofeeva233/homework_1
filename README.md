# Проект Bank_Card
## Описание:
Проект Bank_Card - это проект для работы над виджетом банковский операций клиента.
## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/username/homework_1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте виджет.
2. В нем будут показаны несколько последних успешных банковских операций.
